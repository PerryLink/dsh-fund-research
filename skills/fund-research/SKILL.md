# 基金研究方法论（fund-research）

本技能约束基金研究的**叙述与口径**，不替代计算：一切数字来自 `fund_snapshot` / `fund_research` 工具的确定性产出与封存快照，模型不得自行估算、四舍五入或"补全"任何数字。

## 四步法

1. **采集**：只使用公开免费数据源（天天基金 pingzhongdata / F10 / 东方财富行情快照），每源带 asOf 与 sha256；offline 模式只读快照层。任何需要登录、付费或绕反爬的手段一律不用。
2. **计算**：业绩拆解（区间收益、年化、波动率、最大回撤、Sharpe）、持仓穿透（集中度、HHI、行业分布）、风格归因（规模/估值分档）、经理画像（任期、回报对比）全部由插件纯函数完成；写作时只引用工具返回或报告中的数字。
3. **穿透**：前十大重仓按季度披露口径呈现，显式标注"披露滞后"；行业分布使用本地映射表口径，未映射代码标 `未映射`，不猜测行业归属。
4. **画像**：任期回报与同类对比使用数据源发布口径；同类均值/排名不可得时退用指数基准对比并注明，不虚构分位数。

## 口径定义（写作时复述这些口径，不自创）

- 年化收益：`(1+区间收益)^(365/自然天数)-1`；波动率：日收益标准差×√250；最大回撤：区间内峰值到谷底最大跌幅；Sharpe：`(年化-无风险利率)/年化波动率`，无风险利率为配置项（默认 0.02）。
- HHI：前十大持仓权重（%）平方和，越大越集中。
- 风格分档（估算口径）：规模按总市值固定阈值（大盘≥1000亿、中盘300-1000亿、小盘<300亿），分位为前十大持仓内降序五分位；估值按动态 PE（深度价值<15、价值15-25、均衡25-40、成长≥40）。
- 经理"任期回报"：数据源发布的本基金任期口径；"盈利对比"为经理整体口径（任期收益/同类平均/沪深300），两者不可混用。

## 数据缺口

- 任何缺失维度在对应章节显式声明"数据缺口"，并说明缺哪个源、哪个字段；**禁止**用"估计""约为"填充缺口。
- 需要用户补充数据的情形：数据源连续失败、基金停牌/清盘导致净值序列中断、用户要求 PDF 定期报告级别的明细（v1 不支持）。此时明确告诉用户缺什么、可以从哪里获取（如基金公司官网定期报告），并把该维度留作缺口。

## 合规话术（必须使用）

- 任何研究结论段落以或附"仅供研究参考，不构成投资建议"收尾；不写买卖建议、目标价、仓位建议。
- 引用数字必须带 asOf（"截至 2026-06-30 的前十大重仓"）；预测性表述一律不用。
- 风险提示必备：历史业绩不预示未来表现；持仓为季度披露口径存在滞后。
